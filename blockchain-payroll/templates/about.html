Project Objective

Develop a blockchain-based Payroll Transaction Log System that records employee payroll transactions in blocks and provides blockchain integrity verification using SHA-256 hashing. The application demonstrates how blockchain can maintain a tamper-evident audit log.

Problem Statement

Payroll records require strict integrity. Traditional centralized databases are managed by privileged administrators who can execute SQL modifications without leaving an immutable audit trail. Proving whether historical salary records were modified accidentally or improperly is difficult. A blockchain-based transaction log solves this by creating an append-only, tamper-evident ledger linked via SHA-256 cryptographic digests.

Why Blockchain?

  • Hashing: SHA-256 creates a fixed 64-character hexadecimal digest.
  • Immutability & Tamper Evidence: Any change to payroll data changes the block hash.
  • Linking of Blocks: Each block stores the previous block's hash, forming an unbroken chain.
  • Automated Verification: Continuous integrity audits recalculate hashes on the fly.
  • Transparency: Audit logs can be inspected without trusting a central party.

12-Step Academic Algorithm

  1. Start.
  2. Create Genesis Block.
  3. Set previous hash to "0".
  4. Accept payroll transaction.
  5. Create a new block.
  6. Store previous block hash.
  7. Calculate SHA-256 hash.
  8. Add block to blockchain.
  9. Repeat for additional payroll transactions.
  10. Validate every block.
  11. Display VALID or INVALID status.
  12. Stop.
